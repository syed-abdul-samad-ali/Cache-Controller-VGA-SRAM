# Cache Controller & VGA Display via SRAM

RTL hardware design project integrating a cache memory controller and VGA display interface with single-port SRAM primitives.

## Features
- **SRAM Interface:** Single-port memory read/write access control.
- **VGA Driver Logic:** Timing signal generation for video memory rendering.
- **Digital Logic Circuits:** Sequential counters, shift registers, and FSM controllers.

## Design Tools
- Verilog HDL
- Intel Quartus
- QuestaSim / GTKWave
